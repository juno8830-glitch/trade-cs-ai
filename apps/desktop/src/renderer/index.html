连接状态与回复稿
连上 WorkBuddy 了，回复稿为什么还是模板
绿灯说的是 WorkBuddy 能查你本机的报价表，不是「这个窗口的回复由 WorkBuddy 的 AI 写」。 这个窗口点「生成回复稿」，用的是本机模板助手（看顶部「可用 N / 6 个 AI」：没填密钥时只有模板可用，回复稿下方会写「内置模板助手」），所以措辞会比较固定。 想让 WorkBuddy 用它自己的脑子帮你写，点下面的按钮，把指令粘到 WorkBuddy 对话里就行。
模块说明
客户消息 / 会话记录：本次会话粘贴过的客户原话、企业微信推来的新消息都在左侧这里，最新的排最上面；客户原话的中文翻译在窗口右侧「中文对照」栏，生成回复稿时自动翻好，也可点「翻译这句」手动翻。在客户名称里选老客户会把他的历史聊天一起载进来（灰底虚线是历史，可点「只看本次会话」清掉）。区域可以拖动底边调高，也可以点标题右侧的 ▾ 折叠。
客户信息：点顶部一行摘要展开。新增「客户来源」（INS / 视频号 / Facebook / 客户推荐 / 其他 / 自定义）；勾「保存客户资料与聊天记录」后，客户资料和之后的每条聊天都会写进 data/客户档案.xlsx（客户总览 + 聊天记录 + 阅读说明三张表），点「打开档案」可直接打开。客户名称输入框支持搜索老客户，选中后自动填回资料并显示之前的聊天。展开区限高、内部滚动，不会挤压下面的模块。
这一块平时收起：点顶部工具条的「我的资料库」才从右侧展开，用完再点一下收起。 把报价表、图片、证书直接放进「我的资料库」文件夹，文件名不用改。点一下「整理资料」， 程序会读出表里的型号、价格、货期，之后问报价才会真的去你的表里查。 你的原始文件不会被改名、移动或删除。
左侧白色区域是发给客户的外文正文；中文翻译、中文说明和资料来源统一放在窗口右侧的「中文对照」栏，只给你看，点「只复制正文」时不会带上它们。想把左边拉得更宽，可点右栏标题的「收起」。 客户带图询价并命中型号后，正文下面还会出现随稿产品图，可逐张复制 / 另存为原图。
聊天框里的图片（进 + 出）：客户发图时，直接在输入框按 Ctrl+V 粘贴截图、把图片文件拖进输入框， 或点「加图片」一次选多张（最多 4 张）。图片会以缩略图挂在输入框上，点「生成回复稿」后连同文字 一起变成上面会话记录里的一条消息，点图可放大。命中型号后，回复稿下方会列出资料库里的真实产品图， 可「复制图片」直接粘到微信、「另存为」保存原图，或一键「放进聊天记录」。鼠标停在「加图片」上可预览整个资料库。
这一块平时收起：点顶部工具条的「话术学习」才从右侧展开。点 「记成功」 会写进成功案例库； 点 「记失败」 会变成「下次别这么写」的经验。程序会自动重新归纳话术， 在 WorkBuddy 里说「帮我优化话术」它还会替你写出改进建议并写回， 下一次起草回复稿就自动生效。客户消息和回复稿只存在这台电脑里。
复制、发送与快捷键
复制按钮只取上面的外文正文，中文翻译和注解不会进剪贴板；请自己粘贴到微信 / 企业微信发送，程序不会自动发消息。顶部「重启程序」在窗口卡住、改完配置或重新连接时用。在输入框里按 Ctrl+Enter 可以直接生成回复稿。
桌面窗口版快捷键：Ctrl+Shift+X 唤起 / 隐藏窗口 · Ctrl+Shift+J 抓取剪贴板到输入框。窗口常驻显示，鼠标点别处不会自动消失，只有再按快捷键（或点右上角关闭）才隐藏。X 被别的程序占用时会自动换键，顶栏快捷键徽标和托盘菜单会写明当前生效的键；点徽标可重新抢回 X。
只有浏览器版需要填；桌面窗口版由程序自动保管，界面上看不到口令
