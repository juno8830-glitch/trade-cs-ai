# 客服回复助手 · 外贸客服起草工具

一个跑在本机的外贸客服回复草稿工具：把客户消息（可带产品图）贴进窗口，它按你自己的报价表 / 库存表查价、识别产品图，起草一封外文回复稿给你核对，再由你自己复制去发。**程序不会自动给客户发送任何消息。**

设计重点：报价一律来自你自己的表格、带来源文件名 / 工作表 / 行号，发之前人工核对；查不到就写「待人工补充」，不编价格、不编型号。

---

## 给朋友的安装说明（按这个顺序做）

### 1. 准备环境
- 安装 **Node.js 22 或更高版本**（<https://nodejs.org/>，选 LTS，一路下一步）。
- 把本仓库下载 / 克隆到电脑任意一个文件夹（路径最好不要有中文和空格）。

### 2. 一键启动
- Windows 下双击项目根目录的 **`一键启动.bat`**。
- 第一次运行会自动安装依赖、生成 `.env` 配置文件（大约 1～3 分钟，保持窗口开着）。
- 之后会出一个中文菜单：
  - 选 **1** = 浏览器版（推荐，自动打开操作界面）
  - 选 **2** = 桌面窗口版（窗口常驻，快捷键 `Ctrl+Shift+X` 隐藏 / 显示）
  - 选 **6** = 打开《使用说明书》，第一次用建议先通读一遍

> 那个黑色控制台窗口要一直开着，关掉它 = 程序停止。

### 3. 放自己的资料（关键）
- 把你的库存表 / 报价表（`.xls` / `.xlsx`）放进 `data/客服资料库/` 文件夹。
- 回到黑窗口菜单选 **10**，或在界面点「整理资料」，让程序读懂表格里的型号和价格。
- 如果表里有产品图，鼠标停在界面「加图片」按钮上，点「重建图片索引」，之后客户发图就能按图查价。
- 表内价格按**出厂价 / 内部价**处理，程序会标出来源行，发给客户前请自己核对。

> 本仓库**不包含任何真实报价表、客户资料或产品图片**——这些都是你自己的商业数据，而且会随库存变化，所以请放你自己的文件。程序只读这些文件，不会改名、移动或删除它们。

### 4. 可选：接一个真 AI
- 不填密钥也能用：程序自带离线兜底助手，能起草基础和回复。
- 想让回复更自然、还会自动翻译客户消息，就在黑窗口菜单选 **5 → 1**（智谱 GLM），按提示填自己的 API Key。
- 密钥只存在本机的 `.env` 里，不会上传、不会发给客户。**不要把这个文件分享给别人。**

### 5. 开始用
1. 把客户的外文消息粘贴到窗口下面的输入框，可同时贴产品图（Ctrl+V / 拖入 / 点「加图片」）。
2. 点「生成回复稿」。
3. 左侧是**要发给客户的外文正文**；右侧「中文对照」栏是客户消息译文、回复稿中文翻译、资料来源，只给你看。
4. 想自己写一句英文，可在右栏底部「手动翻译 · 中文 → 英文」输入中文，点「翻译成英文」，再点「一键复制」。
5. 核对价格和来源后，点「只复制正文」或「复制去发送」，**自己去微信粘贴发送**。

## 常见问题
- **改了资料没反应？** 重新点「整理资料」；换了库存表还要重建图片索引。
- **翻译出来是原文？** 说明没连上真 AI 或输入已是目标语言；菜单 5 → 5 可检查 AI 连接。
- **界面改了没生效？** 点右上角「重启程序」两次，或关掉窗口重新打开。
- **更多问题**：界面右上角「?」打开《使用说明书》，或直接看 `使用说明书.html`。

## 技术栈（可选了解）
Electron 桌面窗口 + 本地 Fastify 网关 + TypeScript，Node 22 内置 SQLite，本地图片指纹比对（不调用视觉大模型），零构建步骤。`node_modules/tsx` 直接跑 TS。
